# 추출 검증 범위

지원 형식 전체에서 오류가 없음을 보장하는 인증이 아니다. 판별할 수 없는 구조는 추출을 보류하고 원문 링크를 유지한다.

- 병합 셀: 원래 셀의 식별정보로 중복 확장을 제거한다.
- 비교기간: 연도·분기의 다단 헤더를 함께 보존한다. 헤더가 없거나 중복되어 의미가 불명확한 여러 값은 보류한다.
- 중첩 표: 바깥 표의 항목에 안쪽 표의 값이 붙지 않도록 바깥 표를 보류한다.
- 단위: 앞 표의 단위를 다음 표로 넘기지 않는다. 전체 금액 단위를 비율 항목에 붙이지 않는다.
- 손상: 닫히지 않은 표, 비정상 span, 셀 충돌 등은 거부하거나 해당 표를 보류한다.
- 제한: 깊이·행·열·셀 길이 예산을 넘으면 원문 확인으로 전환한다.
- 알림: 일부 표·항목을 보류하면 알림에 표시한다. 추출 실패로 공시 링크 자체를 버리지 않는다.
- 캐시: 추출 버전 v4를 사용하므로 이전 추출 결과를 재사용하지 않는다. 이미 발송된 메시지는 자동 수정·재전송하지 않는다.

검증: 기존 63종 출력 검증과 실제 제보 형태의 회귀 테스트, 300개 고정 난수 병합 셀 변형, 기간·단위·손상 표 검증. 합성 테스트이며 모든 실제 DART 원문을 전수 검증한 결과는 아니다.
