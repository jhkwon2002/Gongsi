- 기본 알림과 정형 숫자 추출·문장 생성은 AI 없이 구현 가능하다. 복잡한 조건 설명에 AI를 붙이는 것은 추후 선택 사항이다.

## 보존한 코드의 동작

다음은 코드 확인에 따른 설명이며 운영 성공을 의미하지 않는다.

- Setup: 봇 토큰·DART 키를 숨김 입력받고 봇 사용자명과 개인 대화방을 확인한다. 보고서명은 세미콜론으로 여러 개 입력할 수 있고 기본값은 증권발행실적보고서다.
- 전체 기업 공시를 페이지당 100건씩 순회한다.
- 보고서명 앞 대괄호 표시를 제거하고 지정 이름과 정확히 비교한다. 괄호 등으로 이름이 확장된 보고서는 기본값에 자동 포함되지 않을 수 있다.
- 첫 설정 시 당일 기존 공시를 기준으로 저장하고 연결 안내 및 최신 대상 공시 1건을 테스트로 전송한 뒤 예약 작업을 등록한다. 당일 대상 공시가 없으면 공시 테스트 메시지는 보내지 않는다.
- 접수번호로 중복을 방지한다. 정정공시는 이름 필터를 통과하고 새 접수번호이면 전송 대상이다.
- 전송 성공 후 접수번호를 저장한다. 실패한 공시는 재시도할 수 있도록 남긴다. 전송 성공 직후 상태 저장 전에 중단되면 재전송될 가능성은 있다.
- Run: 마지막 성공 조회일부터 현재까지 조회해 신규 공시를 보낸다. 85일 넘게 중단되면 수동 복구 오류를 낸다.
- 실행 잠금과 예약 작업의 중복 실행 방지를 사용한다.
- Status: 예약 작업 상태와 최근 로그를 표시한다.
- Stop: 예약 작업을 비활성화한다.
- SelfTest: 외부 전송 없이 필터, 링크, 중복 방지, 전송 실패 처리를 검사한다.

| 실행·설정 디렉터리 | %LOCALAPPDATA%\AutoDartGongsi |

## 이어서 할 작업

1. 대상 보고서 기본값을 확인하고 새 프로젝트의 스크립트로 Setup을 실행한다.
2. 봇 토큰과 DART 키를 로컬 PowerShell의 숨김 입력란에 입력한다. 채팅·문서·코드·로그에 기재하지 않는다.
3. 실제 DART 조회 결과, 텔레그램 테스트 메시지, SETUP SUCCESS를 확인한다.
4. 예약 작업과 이후 실행 로그를 확인해 5분 주기 동작을 검증한다.
5. 기본 알림이 동작한 뒤 원문 추출·정형 요약의 대상 항목을 정해 확장한다.
