# 원문 HTML 재시도 (2026-10-27)

## 문제와 변경

HD현대일렉트릭 신규시설투자등(20261027800235)은 구조화 API가 없는 유형이며 원문 추출 ValueError 이후 핵심 항목 0개로 발송됐다. 기존 이력만으로는 실패 단계를 확인할 수 없다.

원문 ZIP 다운로드·본문 선택·표 해석에 실패하거나 일치하는 항목이 없으면 같은 접수번호의 DART HTML 본문을 한 번 더 조회한다. DART가 본문에 명시한 viewDoc 또는 문서 트리의 파라미터만 사용하고, 다른 접수번호·여러 문서 후보가 섞인 경우에는 추측하지 않는다. JavaScript를 실행하지 않는다.

API 정상값 보존과 유형별 텔레그램 표시 양식은 유지한다. 인증·접근·호출량 제한 응답은 HTML 재시도를 유발하지 않는다. HTML은 요청당 8초, 4 MiB로 제한하고 추가 요청도 일일 예산에 포함한다. 사이트 구조가 달라 본문을 식별할 수 없으면 단계·고정 사유 코드를 기록한다. 원시 예외 문자열이나 인증키는 보고서에 싣지 않는다.

## 실제 진단

2026-10-27에 한해 해당 HD 공시를 서버 DB에서 읽어 현재 코드로 다시 추출한다. 진단은 완료 또는 최대 3회, 5분 간격으로 제한하며 Telegram 발송·재전송·기존 발송 상태 변경은 하지 않는다. runtime/latest.json의 original_diagnostics에 현재 재조회 결과를 기록한다. 과거 발송을 성공으로 변경하지 않는다.

## 검증

단위 검사는 ZIP 성공 시 HTML 미호출, ZIP/표 실패 시 HTML 재시도, 단계별 오류와 비밀값 비노출, API 값 보존, 접수번호 일치, 모호한 문서 거부, 인코딩과 크기 제한, 시설투자 양식의 금액·비율·목적·기간 표시, 진단 무발송을 확인한다. 실제 원문 대응 여부는 서버 original_diagnostics 결과로 별도 확인한다.
