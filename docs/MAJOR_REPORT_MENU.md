# 주요사항보고서 세부 선택 및 예시

경로: /reports → 경영·계약 → 주요사항보고서 → 전체 또는 36종 세부 선택. 기존 전체 선택은 유지한다. 전체 상태에서 한 세부 유형을 해제하면 명시적 35종 선택으로 전환한다. 정정 공시도 같은 세부 유형으로 분류한다. 다른 분류의 선택은 OR로 함께 적용되며 새 선택으로 과거 공시를 재발송하지 않는다.

아래는 가상 값의 표시 예시다. 실제 반환·추출된 항목만 표시하고, 단위가 확인된 값만 읽기 쉽게 바꾼다. API 지원은 개별 공시의 데이터 반환을 보장하지 않는다.

API 요청 주소: https://opendart.fss.or.kr/api/{코드}.json (또는 .xml)
