# 주요사항공시 — Oracle · GitHub · Telegram

최종 갱신: 2026-10-23 (한국시간)

GitHub: https://github.com/jhkwon2002/Gongsi
Oracle 서버: 생성 완료. 사용자 제공 스크린샷에서 공인 IP·SSH 사용자·리전을 확인했다.
접속 상세는 Git에서 제외되는 로컬 .env.oracle 파일에 보관한다. 개인키 파일 경로와 파일 존재를 확인했다. 사용자 실행 결과로 SSH 접속 성공과 Oracle Linux Server 9.8을 확인했다.

전체 기업의 OpenDART 공시를 5분마다 확인하고, 텔레그램에서 버튼으로 선택한 보고서만 개인 대화방에 전송한다.

- 실행: Oracle Cloud Linux 서버의 상시 서비스. 공시 조회 주기는 기본 300초다.

- 업데이트: GitHub main 변경 → 자동 검사 → 같은 커밋을 Oracle에 배포한다. 서버에서 소스를 직접 수정하지 않는다.
- 보고서 선택: 텔레그램 입력창 옆 메뉴 → 받을 보고서 선택 → 보고서별 체크 버튼. 여러 개 선택 가능하며 즉시 저장한다.
- 봇: @auto_dart_gongsi_bot / 개인 대화방 ID: 6766930417.

## 메뉴 사용 흐름

1. 봇 대화방의 입력창 옆 메뉴를 누른다.
2. ‘받을 보고서 선택’을 누른다.
3. ⬜ 보고서 버튼을 누르면 ✅로 바뀌며 즉시 저장된다.
4. 이전·다음으로 다른 보고서를 선택한다.
5. ‘선택 내역’ 또는 상태 메뉴로 확인한다.

입력창 옆 메뉴는 텔레그램 공식 명령 메뉴다. 그 안에서 보고서 선택을 누르면 메시지에 체크 버튼 목록이 열린다. 별도 웹앱·웹사이트는 필요하지 않다. 버튼의 위치·표시는 텔레그램 앱에 따라 다를 수 있다.

제공 명령: /reports, /status, /pause, /resume. /start도 선택 화면을 연다.

## 알림·저장 정책

- 최초 실행 시 오늘과 전일 공시를 기준으로만 저장하며 과거 공시를 일괄 전송하지 않는다.
- 초기 보고서 선택은 비어 있다. 본인이 메뉴에서 선택한다.
- 새 선택은 다음 조회에서 처음 발견되는 공시부터 적용한다. 이미 조회해 저장한 공시를 재전송하지 않는다.
- 일시정지 중에도 조회는 계속한다. 정지 중 처음 발견한 공시는 재개 후 몰아서 보내지 않는다. 정지 전에 발송 대기 중이던 공시는 재개 후 보낼 수 있다.
- 전송 실패는 대기열에 남겨 재시도한다. 선택 해제한 보고서의 대기 알림은 발송하지 않는다.
- 접수번호 저장 전 프로세스가 종료되는 등 드문 상황에서는 중복 수신 가능성이 있다.
- Telegram 메뉴 수신과 DART 조회를 별도 루프로 실행한다. 메뉴를 누를 때마다 DART를 호출하지 않는다.
- 프로그램은 Telegram getUpdates를 사용한다. 같은 봇을 다른 프로그램에서 동시에 실행하거나 웹훅과 병행하면 안 된다.
- 선택·전송 상태는 Oracle의 /var/lib/gongsi/store.db에 저장하며 배포해도 유지한다.
- 토큰·DART 키는 Oracle의 /etc/gongsi/gongsi.env에 저장한다. GitHub에는 예시 파일과 코드만 올린다.
- 기본 조회 예산은 하루 18,000 API 호출로 제한한다. 이것은 프로그램의 기본값이며 본인 OpenDART 할당량에 맞춰 조정한다.
- 5분은 조회 간격이다. API 응답, 많은 공시 처리, 재시도에 따라 도착은 더 늦어질 수 있다.

## Oracle Linux 설치 재개

프로젝트 폴더에서 PowerShell로 다음 명령을 실행한다.

~~~powershell
& .\deploy\setup-oracle.ps1
~~~

서버 주소·로그인 사용자·개인키 경로는 Git에서 제외된 .env.oracle에서 읽는다. 설치 스크립트는 Oracle Linux 9에 git과 python3.11을 설치하고, 운영체제 기본 Python을 바꾸지 않고 서비스 전용 /opt/gongsi/python3 경로를 사용한다. 서버의 숨김 입력란에서 봇 토큰과 DART 키를 입력하면 인증을 검증하고 환경파일을 저장한 뒤 배포한다. 재실행 시 기존 키는 Enter로 유지할 수 있다.

SETUP SUCCESS 후 텔레그램 /start와 /status로 실제 메뉴·조회 성공을 확인한다. GitHub에서 Oracle로 자동 배포하는 연결은 이후 별도 설정한다.
